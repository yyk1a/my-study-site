如何添加新资料 · 资料站使用指南

更新于 2026-09-27 · 适用站点 yyk1a.github.io/my-study-site · 约 16 KB

概览：到底要做几件事

想往资料站里加一份新资料，本质上只做 两件事，但发布前会拆成三步：

  • 1准备内容页：把新资料做成一个自包含 HTML 文件，放进 materials/ 文件夹。
  • 2在首页挂入口：在根目录 index.html 的 <div class="grid"> 里复制一张 .card，改成新资料的标题、链接和说明。
  • 3重新发布：把改动推送到 GitHub（或网页上传），GitHub Pages 自动更新生效。
关键提醒：“复制卡片”只是给首页加一个入口/封面，并不会凭空生成内容页。第 1 步的内容页必须自己先准备好（或让我帮你生成）。两者缺一，点卡片就会 404。

第 1 步：准备内容页

在仓库根目录的 materials/ 文件夹里，新建一个 .html 文件。例如 python-venv.html。

命名规则

  • 用简短英文小写，单词间用连字符 -，例如 ws63.html、triangle-congruence.html。
  • 别用中文文件名、空格或特殊符号，否则链接容易出乱码。

内容页的要求

  • 自包含：CSS / JS 全部内联在文件里，不要引用任何外部 CDN（你的网络访问 CDN 不稳定，且 Pages 打开必须“不缺格式”）。
  • 中文排版、移动端自适应、浅色主题。
  • 不确定怎么写？直接参考已有的 materials/ws63.html 的样式，照着它的结构填内容即可；或者把资料发给我，我帮你生成。

第 2 步：复制一张卡片

打开根目录的 index.html，找到这一块（它就是首页那排卡片的容器）：

<!-- 卡片容器：里面每个 <a class="card"> 就是一张卡片 -->
<div class="grid">
  <a class="card" href="materials/ws63.html">
    <span class="badge b-dev">嵌入式 · 星闪</span>
    <h3>WS63 实操手册 · 环境搭建 + 编译烧录</h3>
    <p>WSL + VSCode + Ubuntu 下 WS63 SparkLink 开发……</p>
    <div class="meta">更新于 2026-09-27 · 约 24 KB</div>
  </a>
  /* 其它卡片 … */
</div>

“复制一张 .card，改标题、链接和说明”就是：

  • 把上面整段 <a class="card"> … </a> 原样再粘贴一份，放在 <div class="grid"> 里面、和其他卡片平级；
  • 然后只改三处（见下方对照）；
  • 顺手把顶部“目前收录 N 份”的数字 +1。

改之前 vs 改之后（以新增 python-venv.html 为例）

新增的卡片长这样（注意三处变化已用注释标出）：

<!-- 新增卡片：复制自上面那张，只改了三处 -->
<a class="card" href="materials/python-venv.html">   ① 链接：指向新文件
  <span class="badge b-dev">Python · 环境</span>      ② 标签文字（颜色类可换，见下文）
  <h3>Python venv 虚拟环境速查</h3>                ③ 标题
  <p>PEP 668 报错怎么办、venv 创建与激活、依赖导出与复现，一篇讲清。</p>  ④ 说明
  <div class="meta">更新于 2026-09-27 · 约 12 KB</div>
</a>
一句话记住：整张卡就是一个 <a> 链接，点哪里都跳到 href 指向的 materials/xxx.html。你复制出来要改的就是 href、<h3> 文字、<p> 文字这三处。

卡片各部分含义

代码页面上长什么样你要改吗
href="materials/..."点击卡片跳去的地址✅ 必须改（第 1 步的文件名）
<span class="badge b-dev">左上角彩色分类小标签建议改文字；颜色类三选一
<h3>卡片大标题✅ 改
<p>灰色说明文字✅ 改
<div class="meta">底部“更新于…·约 XX KB”建议顺手改日期 / 大小

颜色标签怎么选

左上角那个小标签的颜色，由 badge 后面跟的颜色类决定。目前站点内置三色，直接复用即可：

类名颜色适合场景
b-math绿色数学 / 理科类
b-sec橙色信息安全 / 通用
b-dev蓝色开发 / 工程 / 技术
b-guide紫色本指南这类“站点 / 帮助”页（已随本页新增）
想加第 5 种颜色？在 index.html 的 <style> 里加一条 .b-xxx { background: var(--purple); }（用 :root 里已有的变量色），再把卡片上的类换成 b-xxx 即可。

第 3 步：重新发布

改完 materials/ 里的新文件和 index.html 后，让改动上线有两种方式：

方式 A：命令行（git）

git add index.html materials/你的新文件.html
git commit -m "add: 新增 XXX 资料"
git push

方式 B：GitHub 网页上传（本机命令行连不上 GitHub 时的首选）

  • 浏览器打开 https://github.com/yyk1a/my-study-site；
  • Add file → Upload files，把改好的 index.html 和整个 materials 文件夹一起拖进去（首页覆盖属预期）；
  • 点 Commit changes，等 1~2 分钟；
  • 访问 https://yyk1a.github.io/my-study-site/materials/你的新文件.html 验证，首页按 Ctrl+F5 强刷看新卡片。

常见坑 / 检查清单

  • ✅ href 路径要写对：卡片在根目录 index.html 里，所以链接要写 materials/你的文件.html（相对路径），别写成 /materials/... 或绝对路径。
  • ✅ 代码片段里的 < > & 要转义：如果在卡片说明或页面里贴 HTML 示例，必须把 < 写成 &lt;、> 写成 &gt;、& 写成 &amp;，否则浏览器会把它们当标签吃掉。
  • ✅ 别忘了把“目前收录 N 份”+1，否则数量和卡片数对不上。
  • ✅ 内容页和卡片都要传：只传首页 → 卡片 404；只传内容页 → 首页看不到入口。
  • ✅ 等 1~2 分钟 + 强刷：GitHub Pages 不是实时生效，且浏览器会缓存，务必 Ctrl+F5。
